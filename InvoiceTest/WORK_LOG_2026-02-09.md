| **Platform** | Windows Server |

**Files Created/Modified:**

| File | Location | Purpose |
|------|----------|---------|
| `Dockerfile` | Backend | Django + Gunicorn + Health Check |
| `Dockerfile` | Frontend | Multi-stage Node build + Nginx |
| `nginx.conf` | Frontend | SPA routing + API proxy |
| `docker-compose.yml` | Root | Orchestration with `restart: always` |
| `DOCKER_DEPLOYMENT.md` | Root | Windows-specific deployment guide |

**Docker Configuration Details:**

```yaml
# Key settings in docker-compose.yml
services:
  backend:
    restart: always  # Auto-restart on failure/reboot
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:8000/ || exit 0"]
      interval: 30s
      start_period: 60s
  frontend:
    restart: always
    ports:
      - "80:80"
```

**Issues Encountered & Resolved:**

| Issue | Cause | Solution |
|-------|-------|----------|
| Dockerfile not found | Folder names had "(2)" suffix | Updated docker-compose paths |
| Health check failing (401) | `/api/sales/dashboard/` requires auth | Changed to `curl http://localhost:8000/ \|\| exit 0` |
| Frontend dependency error | Waited for backend health | Changed to simple `depends_on` |
